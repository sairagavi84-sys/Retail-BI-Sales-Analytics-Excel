# Retail-BI-Sales-Analytics-Excel

## Enterprise Retail Business Intelligence & Sales Analytics Dashboard

This project is an interactive Retail Business Intelligence & Sales Analytics Excel Dashboard developed using Microsoft Excel. The project transforms retail transaction data into structured analytical information and presents business performance, customer behavior, sales trends, product performance, and executive-level insights through an interactive Excel dashboard.

## Project Objective
The objective of this project is to analyze retail sales and customer data and convert it into meaningful business insights using Excel. The dashboard helps users understand:
- Overall sales performance
- Order performance
- Customer behavior
- Product and category performance
- Payment status analysis
- Customer segmentation (RFM Analysis)
- Executive-level insights

## Tools & Techniques Used
- Microsoft Excel
- Excel Tables
- Excel Formulas
- Data Cleaning
- PivotTables & PivotCharts
- Slicers
- KPI Cards
- RFM (Recency, Frequency, Monetary) Analysis
- Customer Segmentation
- Data Visualization
- Business Intelligence

## Workbook Structure
The Excel workbook is organized into separate analytical layers:

| Sheet | Description |
|-------|-------------|
| 01_RAW_DATA | Contains the original retail transaction data |
| 02_CLEAN_DATA | Structured and prepared data used for analysis |
| 03_FORMULA_SHEET | Contains formula-based calculations for metrics |
| 04_PIVOT_TABLES | PivotTables summarizing cleaned data |
| 05_DASHBOARD | Final interactive dashboard with KPIs, charts & slicers |

## Dashboard KPIs
- Total Sales Value
- Total Orders
- Total Customers
- Total Units Sold
- Average Order Value

## RFM Customer Analysis
The project includes RFM (Recency, Frequency, Monetary) analysis to evaluate customer behavior and segment customers into:
- Champions / Loyal
- Potential Loyalists
- At Risk
- Low Engagement

## Interactive Slicers
The dashboard uses slicers to filter data interactively by:
- Year
- Country
- Category
- Payment Status

## Executive Insights
- Best Sales Year
- Top Product Category
- Largest RFM Segment
- Order Completion Rate
